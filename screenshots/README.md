## Screenshot guidelines

- Use PNG format and the filenames above.
- Capture readable application windows and relevant details.
- Hide passwords, tokens, private keys, personal data, and other sensitive information.
- Only mark a milestone as verified when the screenshot demonstrates it.

The repository also contains a few additional PNG files with generated UUID filenames. Review their contents before renaming them so each file gets an accurate, descriptive name. Uploading a screenshot alone does not verify the milestone it is intended to demonstrate.
